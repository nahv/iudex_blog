¿Por qué algunas cards no muestran detalle?

Polling cada 30 s. Para ver el body parseado (db/redis/version, agent_loaded) hace falta que cada deploy permita CORS desde https://iudex.com.ar.

En api y staging.api se setea via env var CORS_ORIGINS=https://iudex.com.ar. En nexus y staging.nexus el origen ya viene en iudex-cloud/legali-agent/main.py.

Si una card muestra "Reachable (CORS limita el body)" es que el deploy todavía no tiene el origen configurado — el polling sigue funcionando, solo falta el detalle.
